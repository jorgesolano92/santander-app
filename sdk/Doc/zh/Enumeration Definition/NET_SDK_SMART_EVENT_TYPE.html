    成员说明¶

    枚举名 枚举值 描述
    NET_SDK_SMART_EVENT_TYPE_RANGE_BEGIN 0 开始标识
    NET_SDK_SMART_EVENT_TYPE_OSC 0x05 物品看护侦测事件（仅IPC）。
    NET_SDK_SMART_EVENT_TYPE_AVD 0x06 视频异常侦测事件（仅IPC）。
    NET_SDK_SMART_EVENT_TYPE_VFD 0x0C 人脸侦测（仅IPC）。
    NET_SDK_SMART_EVENT_TYPE_CDD 0xd 人群密度（仅IPC，5.x版本已经没有）。
    NET_SDK_SMART_EVENT_TYPE_IPD 0xe 人员入侵（仅IPC，5.x版本已经没有）。
    NET_SDK_SMART_EVENT_TYPE_CPC 0xf 人数统计（仅IPC，5.x版本已经没有）。
    NET_SDK_SMART_EVENT_TYPE_FACE_MATCH 0x10 人脸比对 for NVR 9000
    NET_SDK_SMART_EVENT_TYPE_FACE_MATCH_FOR_IPC 0x11 人脸比对 for IPC
    NET_SDK_SMART_EVENT_TYPE_PEA_FOR_IPC 0x12 越界侦测与区域入侵侦测 （旧版IPC专属）
    NET_SDK_SMART_EVENT_TYPE_TRAJECT 0x13 目标跟踪轨迹，对于IPC，不需要订阅，对于NVR，需要指定通道开启智能事件订阅。
    NET_SDK_SMART_EVENT_TYPE_VEHICLE 0x14 车牌for IPC
    NET_SDK_SMART_EVENT_TYPE_AOIENTRY 0x15 进入区域for IPC
    NET_SDK_SMART_EVENT_TYPE_AOILEAVE 0x16 离开区域for IPC
    NET_SDK_SMART_EVENT_TYPE_PASSLINE 0x17 按越线统计目标，带有目标抓图相关信息。
    NET_SDK_SMART_EVENT_TYPE_TRAFFIC 0x18 按区域统计目标，带有目标抓图相关信息。
    NET_SDK_SMART_EVENT_TYPE_PEA_TARGET 0x19 周界防范，区域入侵侦测，带有目标抓图相关信息。
    NET_SDK_SMART_EVENT_TYPE_VSD 0x1a 视频二级结构化
    NET_SDK_SMART_EVENT_TYPE_TEMPERATURE_ALARM 0x1b AI告警，温度检测。
    NET_SDK_SMART_EVENT_TYPE_FIREPOINT 0x1c AI告警，火点检测。
    NET_SDK_SMART_EVENT_TYPE_NVR_VEHICLE 0x1d 车牌事件 for NVR
    NET_SDK_SMART_EVENT_TYPE_NVR_AOIENTRY 0x1e 进入区域 for NVR
    NET_SDK_SMART_EVENT_TYPE_NVR_AOILEAVE 0x1f 离开区域 for NVR
    NET_SDK_SMART_EVENT_TYPE_PVD 0x20 违停检测，带抓图信息。
    NET_SDK_SMART_EVENT_TYPE_LOITER 0x21 徘徊检测，带抓图信息。
    NET_SDK_SMART_EVENT_TYPE_ASD 0x22 声音异常，会持续返回设备检测到的声音信息，是否触发报警需自行判断（IPC没有背景音）。
    NET_SDK_SMART_EVENT_TYPE_VFD_MATCH_FAILED 0x23 人脸比对失败。
    NET_SDK_SMART_EVENT_TYPE_BINOCULARCOUNT 0x24 双目人数统计。
    NET_SDK_SMART_EVENT_TYPE_FALLING 0x25 高空抛物。
    NET_SDK_SMART_EVENT_TYPE_TRIPWIRE 0x26 周界防范，跨界侦测，带有目标抓图相关信息。
    NET_SDK_SMART_EVENT_TYPE_HEATMAP 0x27 热力图。
    NET_SDK_SMART_EVENT_TYPE_THERMAL_PEA 0x28 热成像区域入侵，带有目标抓图相关信息，（目前仅支持IPC）。
    NET_SDK_SMART_EVENT_TYPE_THERMAL_AOIENTRY 0x29 热成像通道进入区域，带有目标抓图相关信息，（目前仅支持IPC）。
    NET_SDK_SMART_EVENT_TYPE_THERMAL_AOILEAVE 0x2a 热成像通道离开区域，带有目标抓图相关信息，（目前仅支持IPC）。
    NET_SDK_SMART_EVENT_TYPE_THERMAL_TRIPWIRE 0x2b 热成像跨界侦测，带有目标抓图相关信息，（目前仅支持IPC）。
