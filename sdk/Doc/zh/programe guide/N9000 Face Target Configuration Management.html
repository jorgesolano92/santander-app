    N9000 人脸目标配置管理¶

    人脸目标配置管理包括：目标组信息管理，目标(人脸库)信息管理，通道人脸抓拍信息管理，人脸对比功能，报警上传，以图搜图等

    • 目标组信息管理： 包括创建、修改、删除、查询等操作，通过创建不同的组，可在多个通道内，对组内各人员实现抓拍、录像报警联动等功能。

    • 目标(人脸库)信息管理：包括创建、修改、删除、查询，复制等操作，通过这些操作，实现对不同目标组的目标的添加、修改、删除、查询，复制等操作。

    • 通道人脸抓拍信息管理：查询通道抓图 。

    • 查询人脸抓图：可根据黑名单、白名单、陌生人等事件类型，进行分类查询。

    • 人脸比对功能：将摄像机抓拍的图片与人脸库中的人脸图片进行比对，返回相似度超过设定阈值的人脸信息，包括抓拍的人脸图片、人员属性（性别、年龄、是否戴口罩等）、人脸温度和人脸库中匹配的人脸图片、人员信息（包括姓名、出生日期、性别、移动电话、证件类型和证件号等）。

    • 以图搜图：根据目标图识别结果，检索设备人脸库或者抓拍库里的图片数据。

    • 初始化接口 NET_SDK_Init 在程序开始时调用,一个程序只需要调用一次。

    • 用户注册即登录设备，调用 NET_SDK_Login 接口,每一台设备只需要登录一次。

    • 登录设备之后，通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_GET_FACE_MATCH_SUPPORT）获取是否支持人脸比对库。

    • 目标组管理，包括创建、修改、删除、查询等，相关接口： NET_SDK_FaceMatchOperate，相关命令：

      • 创建目标组：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_ADD_FACE_INFO_GROUP）；
      • 删除指定的目标组：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_DEL_FACE_INFO_GROUP）；
      • 修改指定的目标组：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_SET_FACE_INFO_GROUP）；
      • 查询目标组：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_GET_FACE_INFO_GROUP_LIST）；

      • 创建目标：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_ADD_FACE_INFO）；
      • 删除指定的目标：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_DEL_FACE_INFO）；
      • 修改指定的目标：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_SET_FACE_INFO）；
      • 获取指定目标组人脸信息：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_GET_FACE_INFO_LIST）；
      • 复制指定目标组人脸信息：通过 NET_SDK_FaceMatchOperate（命令：NET_SDK_COPY_FACE_INFO）；

    • 查询通道抓图，通过： NET_SDK_FaceMatchOperate（命令：NET_SDK_SEARCH_CH_SNAP_FACE_IMG_LIST）；

    • 以图搜图，通过： NET_SDK_FaceMatchOperate（命令：NET_SDK_SEARCH_IMAGE_BY_IMG、NET_SDK_SEARCH_IMAGE_BY_IMG_V2）；

    • 退出程序时调用 NET_SDK_Logout  注销设备。

    • 调用 NET_SDK_Cleanup  释放 SDK 所有资源。

string GbkToUtf8(const char *src_str)
{
    int len = MultiByteToWideChar(CP_ACP, 0, src_str, -1, NULL, 0);
    wchar_t *wstr = new wchar_t[len + 1];
    memset(wstr, 0, len + 1);
    MultiByteToWideChar(CP_ACP, 0, src_str, -1, wstr, len);
    len = WideCharToMultiByte(CP_UTF8, 0, wstr, -1, NULL, 0, NULL, NULL);
    char *str = new char[len + 1];
    memset(str, 0, len + 1);
    WideCharToMultiByte(CP_UTF8, 0, wstr, -1, str, len, NULL, NULL);
    string strTemp = str;

    if (wstr)
        delete[] wstr;

    if (str)
        delete[] str;

    return strTemp;
}
string Utf8ToGbk(const char *src_str)
{
    int len = MultiByteToWideChar(CP_UTF8, 0, src_str, -1, NULL, 0);
    wchar_t *wszGBK = new wchar_t[len + 1];
    memset(wszGBK, 0, len * 2 + 2);
    MultiByteToWideChar(CP_UTF8, 0, src_str, -1, wszGBK, len);
    len = WideCharToMultiByte(CP_ACP, 0, wszGBK, -1, NULL, 0, NULL, NULL);
    char *szGBK = new char[len + 1];
    memset(szGBK, 0, len + 1);
    WideCharToMultiByte(CP_ACP, 0, wszGBK, -1, szGBK, len, NULL, NULL);
    string strTemp(szGBK);

    if (wszGBK)
        delete[] wszGBK;

    if (szGBK)
        delete[] szGBK;

    return strTemp;
}
